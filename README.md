# make-knowledge-cards

把文章变成知识卡片的 AI Skill：输入一篇粘贴的文章或本地 Markdown / TXT 文件，
输出 5~8 张结构化的知识卡片，帮你快速抓住要点、加深理解、方便复习自测。

## 解决什么问题

读完一篇长文，记住的往往寥寥无几；让 AI"总结一下"，得到的又常常是
面面俱到、抓不住重点的流水账，还可能掺入原文没有的内容。

本 Skill 解决的就是这个问题：它按一套固定的提炼流程工作——只提取真正
重要的知识、自动删除重复内容、一张卡片只讲一个知识点、绝不编造原文
没有的信息——把任意文章变成可直接用来复习和自测的知识卡片。

## 主要功能

- **两种输入**：直接粘贴文章文本，或给出本地 `.md` / `.txt` 文件路径
- **5~8 张知识卡片**：每张卡片固定包含四个部分——标题、核心知识、简明解释、
  例子或自测问题
- **只留精华**：保留核心概念、关键结论、方法步骤、易错点；背景铺垫、
  重复论述、营销话术一律丢弃
- **自动去重**：同一知识点在原文多处出现只保留一次，表述不同但实质
  相同的点合并为一个
- **绝不编造**：所有数字、结论、例子都必须能在原文中找到依据；
  原文没讲清楚的地方如实标注"原文未说明"，不脑补
- **数量诚实**：有效知识点不足 5 个时按实际数量输出并说明原因，
  不强行凑数；超过 8 个时取最重要的 8 个并提示可继续生成
- **语言一致**：中文文章出中文卡片，英文文章出英文卡片

暂不支持：网页抓取、PDF 解析、Anki 牌组导出、图形界面。
给出网页链接或 PDF 时，Skill 会明确告知暂不支持，而不是假装已读取。

## 安装方法

前置条件：一个支持 Agent Skills 的 AI 客户端。

本 Skill 为纯工作流型，只有一份 `SKILL.md` 说明文档和一份界面元数据，
无依赖、无脚本、无需配置。安装只需复制目录：

```bash
# 把 skill 目录复制到你所用客户端的 skills 目录，例如：
cp -r skills/make-knowledge-cards ~/.codex/skills/      # Codex
cp -r skills/make-knowledge-cards ~/.claude/skills/     # Claude Code
```

复制完成后，在对话中提到"知识卡片"或按客户端的方式调用
`make-knowledge-cards` 即可使用。

本 Skill 已通过官方 `quick_validate.py` 校验（`Skill is valid!`）。

## 使用方法

调用 Skill 后，二选一提供输入：

1. **粘贴文章**：直接把文章文本贴在对话中；
2. **给出文件路径**：提供本地 `.md` / `.txt` 文件的路径，由 AI 读取全文。

之后 AI 会自动完成：提取知识点 → 去重 → 确定卡片数量 → 生成卡片 →
对照检查清单自检 → 在对话中以 Markdown 输出。

原文过短（约 300 字以内）时，AI 会先提醒你内容可能不足以生成 5 张卡片，
经你确认后再继续，此时允许输出少于 5 张。

## 输入输出示例

**输入**（粘贴的文章片段）：

> 间隔重复（spaced repetition）是基于遗忘曲线的学习方法。艾宾浩斯发现，
> 不复习的话 24 小时内会遗忘约 70% 的新知识。正确做法是把复习分散到递增的
> 间隔：1 天后、3 天后、1 周后、2 周后。每次复习都应该是主动回忆——合上书
> 尝试想起答案，而不是被动重读。2006 年 Roediger 和 Karpicke 的研究发现，
> 用自测方式复习的学生，一周后的记忆量比花同样时间重读的学生多约 50%。

**输出**（其中两张卡片）：

## 卡片 1：遗忘曲线

**核心知识**：不复习的话，24 小时内约 70% 的新知识会被遗忘——这是艾宾浩斯发现的遗忘规律。

**简明解释**：遗忘来得又快又猛，所以"学完就放下"是最亏的学习方式。间隔重复整个方法的起点，就是承认这条曲线、并在遗忘发生前安排复习。

**自测**：按遗忘规律，如果你今天学了新知识，最晚应该什么时候复习第一次？

---

## 卡片 2：间隔重复四步法

**核心知识**：把复习分散到递增间隔——1 天后、3 天后、1 周后、2 周后，且每次复习都用主动回忆而非被动重读。

**简明解释**：间隔递增是因为记忆在变牢固，需要的"续费"频率自然降低。主动回忆（合上书想答案）才是真正加固记忆的动作；被动重读只带来"我会了"的错觉。

**例子**：第 1 天学完一章，第 2 天合上书回忆要点，第 4 天再回忆一次，
第 8 天和第 15 天各巩固一次——而不是每天从头读三遍。
