# Make Knowledge Cards（知识卡片生成器）

## 概述

把一篇文章（用户粘贴的文本，或本地 Markdown / TXT 文件）提炼成 5~8 张知识卡片，
帮助用户快速抓住要点、加深理解、方便复习自测。

## 输入

- **粘贴的文章**：用户直接贴在对话中的文本，直接使用。
- **本地文件**：`.md` 或 `.txt` 文件路径，用文件读取工具读取全文（注意处理编码）。
- 若用户给出的是网页链接、PDF 或其他格式：明确说明暂不支持（不做网页抓取、不解析 PDF），
  请用户把内容粘贴出来或转换成 Markdown / TXT 后再试。不要自行尝试抓取或转换。

## 工作流

### 1. 获取原文

- 确认拿到完整原文后再进入下一步。
- 原文过短（少于约 300 字）时：先提醒用户内容可能不足以生成 5 张卡片，询问是否继续；
  用户确认后继续，此时允许输出少于 5 张（见步骤 3）。

### 2. 提取知识点

1. 通读全文，列出所有候选知识点。
2. 只保留真正重要的：核心概念、关键结论、方法步骤、易错点、反直觉的发现。
   背景铺垫、寒暄、重复论述、营销话术一律丢弃。
3. 删除重复内容：同一知识点在原文多处出现只保留一次；
   表述不同但实质相同的点合并为一个。
4. **严禁编造**：每个知识点必须能在原文中找到依据。
   数字、结论、例子、人名、时间都必须来自原文，不得脑补、不得"举一反三"出原文没有的信息。
   具体到卡片各部分：
   - **简明解释**：只能转述、重组原文信息，用自己的话讲清楚"是什么"；
     原文未解释原因或机制的，如实写"原文未说明"，不得编造原因。
   - **例子**：具体细节必须来自原文，或由原文信息直接推导
     （如时间换算、引用其他卡片的知识点）；不得虚构原文没有的行为、场景、数字。
   - **自测问题**：答案或答案提示只能包含原文能支撑的内容；
     开放性思考题可以问，但提示部分不得夹带原文没有的"标准答案"。

### 3. 确定卡片数量

- 默认 **5~8 张**。
- 有效知识点不足 5 个时：按实际数量输出，**不强行凑数**，并在开头一句话说明原因
  （例如："原文有效知识点较少，共提炼出 3 张卡片。"）。
- 有效知识点超过 8 个时：选取最重要的 8 个，在末尾加一句说明还有未覆盖的知识点，
  询问用户是否继续生成剩余部分。

### 4. 生成卡片

按"输出格式"逐张生成。**一张卡片只讲一个知识点**，不把两个概念塞进同一张卡。

- **简短步骤不单独成卡**：能用一两句话或一段代码讲清的操作步骤，
  放入相关概念卡的"例子"部分；只有包含多个步骤、分支判断或易错点的完整流程才独立成卡。

- **标题**：10 字以内，点出知识点本质，不用原文的小标题原样照搬。
- **核心知识**：一句话，给出准确的定义、结论或要点。
- **简明解释**：2~4 句，用自己的话讲清楚"是什么"（原文给出原因的，可一并转述）；
  不复制原文长段落，不堆砌术语。
- **例子或自测问题**（二选一，哪个更有助于理解就用哪个）：
  - 能举例的：给一个具体、贴近生活的例子；
  - 偏概念、不好举例的：给一个自测问题，并附简短答案或答案提示。
- 卡片语言与原文一致（中文文章出中文卡片，英文文章出英文卡片）。

### 5. 自检后交付

输出前对照"质量检查清单"逐项检查，不通过就修改，通过后再交付。
直接在对话中以 Markdown 输出卡片；用户要求保存成文件时再写入文件。

## 输出格式

每张卡片使用以下固定格式（示例为中文，英文原文则用英文）：

```
## 卡片 1：睡眠周期约 90 分钟

**核心知识**：成年人一晚经历 4~6 个睡眠周期，每个周期约 90 分钟，依次经过浅睡、深睡和 REM 睡眠。

**简明解释**：睡眠不是均匀下沉的，而是像波浪一样循环。深睡主要集中在前半夜，负责身体修复；REM 睡眠在后半夜占比更高，与记忆巩固和做梦有关。在周期交界处醒来会感觉清爽，在深睡中被闹钟打断则昏沉。

**自测**：为什么有人睡满 8 小时还是累？（提示：想想是"睡了多久"重要，还是"在哪个阶段被叫醒"重要。）
```

多张卡片之间用 `---` 分隔。开头可加一句导语说明卡片数量，结尾按需加一句"还有未覆盖的知识点"提示。

## 质量检查清单

- [ ] 每张卡片只讲一个知识点，没有一张卡塞两个概念。
- [ ] 简短操作步骤已并入相关卡片的"例子"，没有为两三行命令单独成卡。
- [ ] 没有重复的知识点（同一实质内容只出现一次）。
- [ ] 所有数字、结论、例子都能在原文中找到依据，没有编造；
      解释中没有原文不支持的原因或机制，例子中没有虚构的细节，
      自测的答案/提示没有原文之外的"标准答案"；原文未说明处已如实标注。
- [ ] 数量符合规则：5~8 张；信息不足时更少且已在开头说明；超过 8 个重要知识点时已选最重要的 8 个并提示可继续。
- [ ] 每张卡片四个部分齐全：标题、核心知识、简明解释、例子或自测问题。
- [ ] 语言与原文一致，解释是自己的话而非原文段落复制。

## 不支持的范围

- 网页抓取：用户给链接时不自动抓取，请用户提供文本。
- PDF 文件解析。
- Anki 牌组导出（`.apkg` 等）。
- 图形界面：本 skill 只输出文本卡片，不生成图片或交互页面。

遇到以上情况时，明确告知暂不支持并给出替代做法（粘贴文本 / 转成 Markdown 或 TXT），
不要编造"我已读取"之类的说法。
